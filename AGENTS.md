# Правила разработки проекта Geely ADB Unlock Master

## 1. Концепция и цель проекта
Проект представляет собой универсальное кроссплатформенное решение «в один клик» для постоянной разблокировки отладки по ADB, отключения ограничений установки сторонних приложений (Parrot certificates, AutoInstallVerifier) и интеграции с веб-установщиком GeelyTune на автомобилях Geely (в частности Geely EX5 EM-i с прошивками 2.1.4.5+ / Flyme Auto / Ecarx).

Целевая аудитория — обычные пользователи и пожилые люди, поэтому интерфейс должен быть предельно простым, дружелюбным и автономным («нажал одну кнопку — и всё сделало само»).

---

## 2. Структура директорий и правила размещения файлов

### Корень проекта (`/`)
В корневой папке должны находиться **ТОЛЬКО** 3 понятных пользователю стартовых файла и сервисные директории:
* `СТАРТ_Windows.bat` — запуск для Windows.
* `СТАРТ_Mac.command` — запуск для macOS.
* `СТАРТ_Linux.sh` — запуск для Linux.
* `core/` — вся внутренняя начинка (скрыта от глаз пользователя).
* `.agents/` — системные правила и скилы AI-ассистента.

> ⚠️ **КРИТИЧЕСКОЕ ПРАВИЛО:** Никогда не добавлять в корень проекта временные файлы, вспомогательные скрипты, `.apk`, `.exe` или логи. Всё внутреннее содержимое обязательно должно находиться внутри `core/`.

### Папка `core/`
* `main.py` — главная точка входа автономного CLI/TUI-приложения.
* `engine.py` — независимый движок бизнес-логики (ADB, VHAL, Parrot, AutoInstallVerifier, проверка ГУ).
* `tui.py` — легковесный Zero-Dependency терминальный интерфейс (ASCII-рамки, ANSI-палитра, интерактивное меню).
* `geely_unlock.exe` — скомпилированный автономный бинарник для Windows со встроенным ADB и ресурсами.
* `bin/` — встроенные бинарники Android Debug Bridge:
  * `adb.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll` — для Windows.
  * `adb-darwin` — для macOS.
  * `adb-linux` — для Linux.
* `unlock-hu.sh` — скрипт снятия защиты Parrot и AutoInstallVerifier, запускаемый внутри ГУ.
* `Geely-ADB-Toggle-1.1.0.apk` — вспомогательное приложение переключателя ADB.

## 3. Системные и платформенные требования

1. **Windows Batch файлы (`.bat`):**
   * Всегда сохранять строго с переводами строк **CRLF (`\r\n`)**.
   * Синтаксис команд и `echo` внутри `.bat` должен быть на чистом **ASCII** (латинице), чтобы избежать багов парсера `cmd.exe` в системной кодировке CP866.
2. **Shell-скрипты (`.sh`, `.command`):**
   * Всегда сохранять строго с переводами строк **LF (`\n`)**.
   * Обязательно указывать шебанг `#!/usr/bin/env bash`.
   * Включать авто-раздачу прав `chmod +x` на бинарники ADB и скрипты.
3. **Python движок и TUI (`core/engine.py`, `core/tui.py`, `core/main.py`):**
   * Строго **Zero-Dependency**: никаких внешних `pip`-зависимостей (только стандартная библиотека Python: `subprocess`, `threading`, `time`, `os`, `sys`, `ctypes`, `platform`, `webbrowser`, `urllib`).
   * Для Windows консоли обязательно использовать включение ANSI VT100 через `ctypes.windll.kernel32.SetConsoleMode` и безопасный вывод `sys.stdout.reconfigure(encoding='utf-8')`.
   * При компиляции через PyInstaller: ресурсы (ADB, скрипт, APK) зашиваются внутрь бинарника и извлекаются через `get_resource_path()` (`sys._MEIPASS`).
4. **Процессы:**
   * Перед началом работы движок автоматически очищает старые зависшие процессы ADB (`taskkill /F /IM adb.exe` / `killall -9 adb`).

## 4. Алгоритм разблокировки Geely

1. **Шаг 1: Аппаратная перемычка:**
   * Установка перемычки в разъём ГУ для временной активации сервисного ADB в момент загрузки.
2. **Шаг 2: Сброс настроек (Factory Reset) и перехват 20-секундного окна:**
   * Циклический опрос `adb get-state`.
   * Запрос `adb root`, `adb wait-for-device`, `adb remount`.
   * Отправка VHAL команды фиксации постоянного ADB:
     `/system/bin/lshal debug android.hardware.automotive.vehicle@2.0::IVehicle/default --set 557872680 i 0 a 0`
   * Проверка ответа: наличие `Set property` подтверждает успех.
3. **Шаг 3: Снятие перемычки и перезагрузка:**
   * Извлечение перемычки, `adb reboot`, ожидание `sys.boot_completed=1`.
4. **Шаг 4: Снятие ограничений установки:**
   * Заливка `unlock-hu.sh` в `/data/local/tmp/gt-unlock.sh`.
   * Отключение `com.ecarx.xsfinstallverifier` и системных верификаторов.
   * Установка `ro.vendor.ecarx.app_verify=false` в `/product/build.prop`.
   * Установка `Geely-ADB-Toggle-1.1.0.apk` через `adb install -r --user 10 ...`.
5. **Шаг 5: Переход к GeelyTune:**
   * Открытие официального веб-установщика `https://geelytune.github.io` в браузере по умолчанию.
