# Geely ADB Unlock Master (Universal Edition)

Кроссплатформенная утилита для активации отладки по ADB, отключения заводских ограничений установки сторонних приложений (Parrot certificates, AutoInstallVerifier) и подготовки мультимедиа к установке твиков GeelyTune на автомобилях Geely (включая Geely EX5 EM-i, Galaxy E5, Flyme Auto, Ecarx).

Программа работает полностью автономно: не требует установки Python, сторонних библиотек или ручной настройки драйверов.

---

## 📋 Таблица совместимости прошивок

| Прошивка авто | Защита установки | Особенности ADB и Root | Что применять в программе |
| :--- | :--- | :--- | :--- |
| **Ранняя (< 2.1.4)** | Вшита в `/system/etc/security/parrot` (без выключателя) | ADB открывается стандартно через перемычку | Пункт **`[T] Parrot Trust`** (подпись и установка APK сертификатом) |
| **2.1.4.5 / 2.1.4.6** | Управляется параметром `ro.vendor.ecarx.app_verify=true` | Классический ADB, стандартный `adb root` | Пункт **`[2] Открыть ADB с нуля`** ➔ затем Пункт **`[1] Снять защиту`** |
| **2.2.0 / GMC (после обновления)** | Защита Parrot снята производителем | ADB сохраняется, но `adb root` заблокирован | Перемычка **НЕ нужна**. Пункт **`[1] Снять защиту`** (восстанавливает root и слои scratch) |
| **2.2.0 с завода (новые авто ОД)** | Защита Parrot снята производителем | Аппаратный перехват перемычкой может быть закрыт в загрузчике | Требуется однократная активация ADB (софтанлок), затем Пункт **`[1]`** |

## ⚡ Быстрый запуск

### Запуск из готового репозитория:
* **Windows:** запустите `СТАРТ_Windows.bat` (использует встроенный автономный бинарник `core/geely_unlock.exe`).
* **macOS:** запустите `СТАРТ_Mac.command` (или в терминале: `./СТАРТ_Mac.command`).
* **Linux:** запустите `СТАРТ_Linux.sh` (или в терминале: `./СТАРТ_Linux.sh`).

## 🛠️ Что программа делает под капотом

### 1. Первичное открытие ADB (Пункт 2 меню)
Применяется для автомобилей с закрытым с завода портом ADB.
* **Перемычка:** замыкает сервисный контакт в разъёме ГУ на массу (GND), сигнализируя процессору о переходе в сервисный режим.
* **Сброс настроек (Factory Reset):** на экране авто выбирается *«Основное приложение» ➔ «Мой автомобиль» ➔ «Сброс к заводским настройкам»*. В момент перезагрузки открывается 13–20 секундное служебное окно.
* **Fast-Catcher (0.2с):** алгоритм непрерывно опрашивает шину USB, моментально перехватывает устройство и отправляет команду VHAL:
  ```bash
  /system/bin/lshal debug android.hardware.automotive.vehicle@2.0::IVehicle/default --set 557872680 i 0 a 0
  ```
  Параметр `USB_SWITCH=0` фиксирует постоянный режим ADB в энергонезависимой памяти блока. Перемычка извлекается — порт остаётся открытым навсегда.

### 2. Снятие ограничений установки и адаптация 2.2.0 (Пункт 1 меню)
Применяется, когда ADB уже активен (с завода, после перемычки или после обновления прошивки).
* **Ядро GeelyTune 26-11-11.2:** использует актуальный скрипт `unlock-hu.sh`.
* **Адаптивный Root (`ensure_root`):** для версий 2.2.0 и GMC, где стандартный `adb root` сбрасывается, применяется циклический вызов `setprop service.adb.root 1; setprop ctl.restart adbd`.
* **Изоляция старых оверлеев (`park`):** в разделе `scratch` архивирует старые несовместимые слои предыдущей прошивки, исключая зависания системы.
* **Отключение верификаторов:** отключает службу `com.ecarx.xsfinstallverifier` и системные проверки `package_verifier_enable`.
* **Снятие Parrot:** для 2.1.4.5 переводит `ro.vendor.ecarx.app_verify` в `false`; для 2.2.0 пропускает проверку, так как защита снята заводом.
* **Тумблер переключения:** устанавливает на экран авто приложение `Geely-ADB-Toggle-1.1.0.apk`.

### 3. Режим Parrot Trust (Пункт T меню)
Специальный режим для ранних версий прошивок (< 2.1.4.5), где отключить Parrot глобально невозможно.
* Извлекает открытый X.509 сертификат из любого передаваемого `.apk` (с поддержкой схем подписи APK v1, v2 и v3).
* Помещает сертификат в доверенное хранилище ГУ `/system/etc/security/parrot/`.
* Позволяет установить конкретное приложение в обход заводской блокировки.

## ⏱️ Особенности работы на Windows 11

Если процедура первичного перехвата (Пункт 2) не срабатывает с первого раза:
1. **Причина:** в Windows 11 включены *Core Isolation (Изоляция ядра / HVCI)* и глубокое энергосбережение USB. В момент перезагрузки ГУ операционная система тратит 4–7 секунд на переинициализацию PnP-стека USB, из-за чего короткое сервисное окно может успеть закрыться.
2. **Решение в коде программы:** мы удалили задержку `remount` из окна перехвата и подняли частоту опроса до 0.2 секунды.
3. **Рекомендации пользователю:**
   * Подключайте кабель USB-A напрямую в порт на материнской плате ноутбука (без USB-хабов и переходников).
   * В настройках электропитания Windows отключите параметр *«Временное отключение USB-порта» (USB Selective Suspend)*.

## 🧪 Виртуальный стенд-эмулятор ГУ

В состав дистрибутива входит интерактивный терминальный эмулятор мультимедиа Geely:
👉 `core/ЭМУЛЯТОР_ГУ.bat` *(или `python core/emulator.py`)*

Эмулятор позволяет проверить весь функционал программы прямо на ПК без подключения к машине:
* Переключение между 3 профилями прошивок (`ранняя`, `2.1.4.5`, `2.2.0`).
* Симуляция физической перемычки (`[J]`).
* Симуляция сброса настроек с обратным отсчетом 13-секундного окна (`[R]`).
* Проверка VHAL-ответов, логики `gt_root`, монтирования и установки APK.

Приложение автоматически распознает запущенный эмулятор и переключается на него. После закрытия эмулятора программа сразу готова к работе с реальным автомобилем.

## 🛡️ Безопасность

* **Изоляция системных разделов:** программа не выполняет низкоуровневых операций записи в загрузчики (`bootloader`, `xbl`, `abl`, `gpt`).
* **Контроль `dm-verity`:** на прошивках 2.2.0 системные файлы не модифицируются напрямую.
* **Сторожевой таймер (Rescue Mode):** если после перезагрузки ГУ не выходит на связь более 5 минут, автоматически активируется откат оверлеев (`rescue`), возвращающий ГУ в стабильное заводское состояние.
