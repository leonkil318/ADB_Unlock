# Geely ADB Unlock Master 🚀

Универсальное кроссплатформенное решение «в один клик» для постоянной разблокировки отладки по ADB, отключения ограничений установки сторонних приложений (Parrot certificates, AutoInstallVerifier) и интеграции с веб-установщиком GeelyTune на автомобилях Geely (в частности Geely EX5 EM-i с прошивками 2.1.4.5+ / Flyme Auto / Ecarx).

---

## ⚡ Быстрый старт

Проект готов к работе сразу после распаковки — встроенный интерфейс запустится в вашем браузере.

### Windows
Запустите файл:
```text
СТАРТ_Windows.bat
```
*(Не требует предварительной установки Python, используется готовый автономный бинарник `core/geely_unlock.exe`).*

### macOS
Запустите файл:
```bash
СТАРТ_Mac.command
```
*(Или в терминале: `./СТАРТ_Mac.command`)*

### Linux
Запустите файл:
```bash
СТАРТ_Linux.sh
```
*(Или в терминале: `./СТАРТ_Linux.sh`)*

## 📋 Пошаговый процесс разблокировки

1. **Шаг 1: Аппаратная перемычка**
   - Установите сервисную перемычку в диагностический разъём ГУ для временной активации инженерного ADB в момент старта.
   - Подключите ноутбук к сервисному USB-порту автомобиля.
2. **Шаг 2: Сброс настроек (Factory Reset)**
   - Выполните сброс до заводских настроек на экране автомобиля.
   - Скрипт автоматически циклически опрашивает порт и перехватывает 20-секундное окно root-доступа.
   - Отправляется VHAL-команда фиксации постоянного ADB (`USB_SWITCH=0`).
3. **Шаг 3: Снятие перемычки и перезагрузка**
   - Извлеките аппаратную перемычку.
   - Нажмите кнопку «Перезагрузить ГУ» в интерфейсе и дождитесь полной загрузки системы.
4. **Шаг 4: Снятие ограничений установки**
   - Нажмите «Снять ограничения и завершить».
   - Скрипт отключит верификаторы Parrot и AutoInstallVerifier (`ro.vendor.ecarx.app_verify=false`).
   - Будет установлен системный переключатель `Geely-ADB-Toggle`.
5. **Шаг 5: Установка приложений**
   - Нажмите кнопку открытия веб-установщика [GeelyTune](https://geelytune.github.io) для комфортной установки приложений прямо из браузера.

## 📁 Структура проекта

```text
├── СТАРТ_Windows.bat        # Запуск для Windows
├── СТАРТ_Mac.command        # Запуск для macOS
├── СТАРТ_Linux.sh           # Запуск для Linux
├── README.md                # Документация проекта
├── core/                    # Внутренние компоненты
│   ├── web/index.html       # Автономный веб-интерфейс (темная тема)
│   ├── server.py            # Локальный HTTP REST-сервер и диспетчер команд
│   ├── geely_unlock.exe     # Автономный бинарник для Windows
│   ├── bin/                 # Встроенные бинарники Android Debug Bridge
│   │   ├── adb.exe          # Google ADB для Windows (+ DLL)
│   │   ├── adb-darwin       # ADB для macOS (Universal)
│   │   └── adb-linux        # ADB для Linux (x86_64)
│   ├── unlock-hu.sh         # Скрипт снятия системных ограничений ГУ
│   └── Geely-ADB-Toggle...  # APK системного переключателя
└── .agents/                 # AI-правила и база знаний разработки
```
